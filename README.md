# DiCrypto
⚠️ EDUCATIONAL PURPOSES ONLY - Python toolkit for cryptography
A modular, menu-driven command-line toolkit for learning and experimenting with
hashing, hash cracking, symmetric encryption, and asymmetric cryptography —
all in a single Python script.
